# Homework_02
## Описание:
На данный момент это - заготовка приложения для работы интернет-магазина.
Было создано 2 класса - Category и Product, для создания отдельных экземпляров - товарных единиц и их категорий
соответственно.

Были добавлены подклассы класса Product: Smartphone и LawnGrass для представления смартфонов и газонной травы
соответственно. Был реализован функционал, позволяющий вычислять суммарную стоимость 2 экземпляров одинакового
класса (Product, Smartphone или LawnGras), а также возможность добавлять экземпляр класса Product в экземпляр
класса Category.
## Установка:
1. Клонируйте репозиторий
```
git clone https://github.com/LeslieShmit/homework_1.git
```
2. Установите poetry в качестве пакетного менеджера
```
poetry init
```
3. Установите необходимые зависимости
```
poetry install
```
## Тестирование:
Для тестирования проекта используется зависимость pytest.
Для тестирования запустите следующий код:
```
pytest
```
